# 📊 Data Engineering Project – Data Warehouse Development

## 📌 Project Overview

This project focuses on building a **Data Warehouse System** that integrates data from multiple sources (**ERP & CRM**) to support analytics and data-driven decision-making.

---

## 🎯 Agenda

Build a scalable **Data Warehouse** to store, clean, and integrate enterprise data for analytical purposes.

---

## 🗂️ Project Steps

### 1️⃣ Dataset Collection

Download datasets from the following sources:

* **ERP System**
* **CRM System**

---

### 2️⃣ 🛠️ Required Tools

| Tool                                | Purpose                            |
| ----------------------------------- | ---------------------------------- |
| SQL Server Express                  | Database server to host data       |
| SSMS (SQL Server Management Studio) | Database management & querying     |
| GitHub                              | Version control & collaboration    |
| Draw.io                             | Data architecture & model diagrams |
| Notion                              | Project tracking & documentation   |

---

### 3️⃣ 📋 Requirement Analysis

Develop a **Data Warehouse using SQL Server** to store and integrate data from ERP and CRM systems for analysis and decision-making.

#### ✅ Key Requirements

* **Data Sources:** ERP & CRM
* **Data Quality:** Clean and resolve data issues before analysis
* **Integration:** Combine both sources into a single unified dataset
* **Scope:**

  * No historization required
  * Focus only on **latest data**
* **Documentation:** Provide clear documentation for Data Analysts and end users

---

### 4️⃣ 🏗️ Data Architecture

The project follows the **Medallion Architecture**:

```
Database → Bronze Layer → Silver Layer → Gold Layer → BI Tools
```

#### Architecture Layers

* **Bronze Layer** → Raw data ingestion from source systems
* **Silver Layer** → Data cleaning and transformation
* **Gold Layer** → Business-ready analytical datasets
* **BI Tools** → Reporting and visualization

---

### 5️⃣ 🎨 Data Architecture Design

* Design architecture diagrams using **Draw.io**
* Visualize data flow and layer transformations
